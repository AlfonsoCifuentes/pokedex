# Pokédex

> Pokedex Educativa con JavaScript Vanilla

## Resumen

Un proyecto educativo Pokedex desarrollado como parte del programa Full Stack Developer (FSD) que implementa funcionalidades completas de exploración Pokemon usando JavaScript vanilla. El proyecto enfatiza fundamentos sólidos de desarrollo frontend sin frameworks, demostrando dominio de conceptos básicos esenciales.

## Valor del proyecto

Demuestra dominio sólido de fundamentos web esenciales, capacidad para desarrollar sin dependencias de frameworks, y habilidades para crear aplicaciones eficientes con tecnologías base.

Este repositorio resume una pieza de producto pensada para explicar el problema, la solucion aplicada y el criterio tecnico detras de la implementacion.

## Funcionalidades o puntos fuertes

- Catálogo completo de Pokemon con JavaScript puro
- Integración nativa con Pokemon API
- Manipulación avanzada del DOM sin frameworks
- Sistema de búsqueda y filtrado implementado desde cero
- Interface responsive construida con CSS puro
- Manejo de estados y eventos con JavaScript vanilla
- Optimización de rendimiento sin librerías externas
